# 考勤打卡项目

FaceAttandence[客户端--考勤打卡端]:   
　　Qt桌面程序，打开本地摄像头采集视频流，做人脸识别检测，把含人脸的画面编码后经TCP发给服务端，并接收识别结果展示；  
  FaceServer[服务端--识别+管理端]:  
　　Qt桌面程序，监听TCP端口，接收图像后调用 SeetaFace2 完成人脸识别，关联 SQLite 数据库完成员工信息匹配与考勤记录写入，另含注册与查询界面  
  
**平台工具**：Qt 5（Qt Creator / qmake / MinGW）、OpenCV 4.5.2、SeetaFace2、SQLite、Windows
  
  **项目内容**：

1. 采用 **C/S 架构**，基于 Qt 的 `QTcpServer` / `QTcpSocket` 实现服务端与客户端的网络通信，支持图像数据的可靠收发，将网络通信与业务逻辑解耦。
2. 设计 **自定义应用层协议**：使用 `QDataStream` 以"长度前缀 + 数据体"的帧格式传输，解决了 TCP **粘包/半包**问题；图像经 OpenCV 编码为 JPG 压缩后再传输，降低带宽占用。
3. 基于 Qt **多线程**（`QThread` + `moveToThread`）将耗时的人脸识别任务放入独立子线程执行，通过信号槽跨线程投递任务与回传结果，避免识别过程阻塞主线程，保证界面与网络响应流畅。
4. 通过 `qRegisterMetaType` 注册自定义元类型（`cv::Mat`、`int64_t`），实现图像与识别结果在跨线程信号槽中的安全传递。
5. 使用 **OpenCV** 完成摄像头实时采集（`VideoCapture`）、灰度转换、尺寸归一化与 Haar 级联分类器的人脸检测；实现 `Mat` 与 `QImage` / `QPixmap` / `QByteArray` 之间多种格式的高效互转。
6. 集成 **SeetaFace2** 人脸识别引擎（检测 FD / 关键点 PD / 识别 FR 三模型），实现人脸注册与 1:N 检索；通过相似度阈值（0.75）判定识别结果，控制误识别率。
7. 使用 **JSON**（`QJsonDocument`）序列化服务端返回的人员信息（工号、姓名、部门、时间），客户端解析后完成打卡结果的界面回显。
8. 使用 **SQLite** 关系型数据库存储员工信息与考勤记录，设计 `employee` 表与 `attendance` 表并通过 `faceId` 关联，实现"人脸识别 → 人员匹配 → 考勤自动登记"的业务闭环。
9. 基于 `QSqlTableModel` + `QTableView` 实现员工信息与考勤记录的查询界面，实现注册端人脸采集与信息入库功能。
10. 客户端实现**断线自动重连**机制，服务端对人脸特征库（`face.db`）做持久化，提升系统在实际使用中的健壮性。

**其它 · 可升级处**：

- 服务端识别线程目前为单任务串行，可改为线程池 / 任务队列以提升多人并发打卡的吞吐。
- 服务端当前仅维护单客户端套接字，可扩展为连接管理与多客户端并发处理。
- 可引入 MySQL 替换本地 SQLite，并配合连接池提升数据库读写性能；可引入 Nginx 做 TCP 负载均衡、Redis 做跨服务消息通信，实现服务集群化。
- 图像与人脸特征库当前明文存储，可增加传输与存储加密；服务端可引入日志系统与更完善的异常处理。
- 界面可进一步用 Qt Quick / Electron 做现代化改造，并将硬编码的模型路径、部门信息等改为配置化管理。
